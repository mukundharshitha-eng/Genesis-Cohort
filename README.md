In this assignment, I learned SQL queries like SELECT,DISTINCT,AGGREGATIVE FUNCTIONS LIKE COUNT,MIN,MAX. The SELECT statement displays specific columns from the table. DISTINCT shows only unique city names. ORDER BY sorts the data based on LoanAmount in descending order, and LIMIT displays only the top five records. I also used aggregate functions: COUNT() counts the total customers, SUM() calculates the total loan amount, MIN() finds the minimum balance, MAX() finds the maximum balance, and AVG() calculates the average balance. These queries help organize and summarize the data efficiently.
